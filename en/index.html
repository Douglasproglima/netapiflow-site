Engineering manifesto

Four principles that do not bend

01

Strongly Typed (.NET)

Native DI and ASP.NET Core middleware integration. Typed tracking events, no magic strings or reflection on the critical path.

02

Active Diagnosis

Shows where the failure began, what got slow, and what never executed. State is always color plus icon plus text, never just color.

03

Fluent Configuration

One NuGet package, a couple of lines of code, one local URL. Filters by layer, route and tenant composed in a fluent API.

04

Zero Overhead

Asynchronous collection, toggleable per environment. The request never waits on the dashboard to respond.

What it does

Three pillars

Live

Live Tracking

Real time graph of the request path. Endpoint, then Handler, then Services, then Repositories, then SQL. Works with Clean Architecture, Vertical Slices and MediatR.

Diagnose

Failure & Latency Diagnosis

Duration per step, exception origin, slow steps above threshold, and what never executed, without opening a debugger or mining logs.

Replay

Telemetry & Replay

Execution history with trace ID, filter by tenant and route, and a replay timeline with speed control to see exactly what happened.

Get started

Install one package, add a few lines

No separate service to deploy. The dashboard ships embedded in the package and runs next to your API.

Program.csillustrative example
// 1. install the package
dotnet add package NetApiFlow

// 2. register and mount the dashboard
builder.Services.AddNetApiFlow();
builder.Services.AddNetApiFlowDashboard();
// ...
app.UseNetApiFlowDashboard("/flow");

Every step, color plus icon plus text

State is never color alone. It stays readable in grayscale, for color blind users, and on a black and white printout.
